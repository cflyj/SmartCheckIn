# Deep Research — reference

## PRISMA 2020 (conceptual cues)

Adapt flow reporting even when you only produce text (no Figure): always state reasons for exclusions at abstract vs full-text when possible.

## Socratic prompts (reuse)

1. Which finding would collapse if sampling bias exists?
2. What counter-evidence pattern would overturn the narrative?
3. Are correlational results being sold as causal?
4. Is the novelty claim scoped to deployment context only?
